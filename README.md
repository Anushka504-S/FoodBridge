# 🍽️ FoodBridge – Food Donation Website

A responsive **Food Donation Website** built using **HTML5** and **CSS3**.  
FoodBridge aims to reduce food waste by connecting food donors with people and organizations in need.

---

## 📖 About the Project

FoodBridge is a frontend web project that provides a simple and user-friendly interface for food donation. The website encourages users to donate surplus food and promotes social responsibility through an attractive and responsive design.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🍱 Food Donation Page
- 👥 Volunteer Registration Page
- ℹ️ About Us Page
- 📞 Contact Page
- 🎨 Modern UI Design
- 📱 Responsive Layout
- 🧭 Easy Navigation
- 💚 Clean and Simple User Interface

---

## 🛠️ Technologies Used
